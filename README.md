# ZeroScript-Free

This repo is a browser-extension scaffold for using ZeroScript with Claude Web and ChatGPT Web in addition to the existing browser AI providers.

## Included

- Chrome extension manifest
- background service worker
- popup UI
- provider integrations for:
  - ChatGPT Web (`chatgpt.com`, `chat.openai.com`)
  - Claude Web (`claude.ai`, `www.claude.ai`)

## Notes

This project is intentionally lightweight and designed to be extended with the full Roblox bridge integration you already use in the original ZeroScript project.
